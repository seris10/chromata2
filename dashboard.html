Overview

Data Flow: Image loads into sourceCanvas → Optional edge detection pre-processing → Image converted to 2D pixelArray → PathFinders seeded at origin positions → Animation loop: pathfinders read pixels, calculate next position → PathRenderers draw lines/curves/dots to renderCanvas
PathFinder Algorithm: Samples arc ahead (turningAngle width, sampleSize divisions), finds pixel with best color match based on key (low=bright, high=dark), avoids visited pixels via workingArray, bounces at canvas edges.

Configuration

17 parameters

Movement & Physics

speed
Pixels traveled per step - affects tracing accuracy and visual rate
Range: 1-100 Default: 7
stepsPerFrame NEW
Decouples visual speed from accuracy. Steps per animation frame.
Range: 1-20 Default: 1
turningAngle
Arc width for direction sampling in radians
Range: 0.1-10 Default: Math.PI
sampleSize NEW
Directions tested within arc. Higher = smoother, lower = angular
Range: 2-32 Default: 16
jitter NEW
Random wobble for hand-drawn feel. Applied as angle offset.
Range: 0-2 Default: 0
pathFinderCount
Number of simultaneous path tracers
Range: 1-10000 Default: 30

Rendering & Style

colorMode
RGB color cycling or monochrome output
Values: 'color' | 'greyscale'
compositeOperation
Canvas blend mode for drawing
Values: lighten, darken, source-over, difference, screen
lineMode
smooth = curves, square = lines, point = dots
Values: 'smooth' | 'square' | 'point'
lineWidth
Stroke thickness in pixels
Range: 1-100 Default: 2
lineOpacity NEW
Line transparency for layered/soft effects
Range: 0-1 Default: 1
key
low = seek bright pixels, high = seek dark
Values: 'low' | 'high'

Image Processing

edgeDetect NEW
Sobel edge detection mix. 0=original, 1=pure edges. Critical for sketch.
Range: 0-1 Default: 0
edgeStrength NEW
Edge detection intensity multiplier
Range: 0.5-3 Default: 1

Initialization

origin
Where pathfinders spawn from
Values: ['top', 'bottom', 'left', 'right', 'X% Y%']
outputSize
Use original image size or fit to container
Values: 'original' | 'container'
iterationLimit
Stop after N iterations (0 = unlimited)
Default: 0
pathMemory NEW
PathQueue size - points remembered for backtracking
Default: 10
