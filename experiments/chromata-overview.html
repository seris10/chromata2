Original Baseline Functionality

Chromata is a JavaScript library by Michael Bromley that transforms images into animated artwork using autonomous path-finding agents.

How It Works

Path Finders

Autonomous agents seeded at canvas edges that traverse the image, reading pixel color data to determine their path.

Color Distance

Simple single-channel RGB comparison: MAX - pixel[rgbIndex]. Fast and effective for path decisions.

Arc Sampling

Fixed sample size of 4 points in a forward arc. Consistent angle steps create smooth, predictable curves.

Rendering

Two color modes: color (RGB trails) or greyscale. Uses canvas gradients between path points.

Intended Enhancements

CIE LAB Color Distance

Perceptually uniform color matching using LAB color space with Delta E formula.

Weighted RGB Distance

Redmean formula accounting for human eye sensitivity to different colors.

WebGL Edge Detection

GPU-accelerated Sobel edge detection to guide path finders along image edges.

Face Detection

OpenCV.js Haar Cascades to detect faces and apply smooth skin rendering.

Adaptive Sampling

Dynamic arc sample count (2-10) based on edge strength and face regions.

Gradient Caching

Reuse canvas gradients by color for ~15% rendering speedup.

Broken What Went Wrong

Complete Failure - December 2025

Every modified function performed worse than the original. Output was "unrecognizable" - messy black scribbles instead of beautiful colored trails. 128 seconds of processing produced worse results than 60 seconds with the original.

Critical Failures (Ranked by Severity)

Color Distance Broken

LAB/weighted distance returns different scale than expected (not 0-255). Path finders make wrong decisions, resulting in random wandering.

Greyscale Output

pathRenderer only recognizes 'color' or 'greyscale'. Setting 'weighted' or 'lab' falls through to greyscale rendering.

Adaptive Sampling

Changing sampleSize mid-path destroys smooth tracing. Different sample counts = different arc divisions = jerky paths.

Edge Bias

Multiplying colorDistance by edge bias corrupts the comparator logic. Path finders pick wrong pixels.

Async Initialization

Race condition: paths might start before preprocessing completes. Silent failures possible.

Gradient Cache

Caches by color only, ignoring position. Gradients are position-dependent, causing visual artifacts.

Root Causes

  • Did not test original behavior before modifying
  • Changed core algorithms without understanding the downstream effects
  • "Better" color matching doesn't help if path logic is broken
  • Created module incompatibilities (pathFinder colorMode != pathRenderer colorMode)
  • Made everything async without proper error handling
  • Chromata's beauty comes from SIMPLE, consistent path-following

Proposed Recovery Plan

Four-phase approach to restore functionality and properly implement enhancements.

1 Restore Basic Functionality
  • Change all presets to colorMode: 'color'
  • Revert _getColorDistance() to original single-channel method
  • Remove adaptive sampling logic from pathFinder
  • Remove edge bias multiplication
  • Remove colorMode: 'weighted' default from chromata.js
2 Fix Rendering
  • Fix or remove gradient caching (include position in cache key)
  • Verify pathRenderer works with original logic
  • Test output matches original chromata quality
3 Make Enhancements Optional
  • Add explicit flags to enable/disable new color distance methods
  • Make preprocessing opt-in, not default
  • Ensure default behavior matches original exactly
4 Verify Enhancements Work
  • Test if LAB distance actually helps (probably doesn't)
  • Test if face detection adds value (probably doesn't)
  • Test if edge detection improves output
  • Remove what doesn't work

Key Insight

"Chromata's beauty comes from SIMPLE, fast, consistent path-following. 'Perceptual color' doesn't matter if path-finders can't follow paths. Adaptive sampling destroys the smooth curves that make it work."

The original algorithm works because of its elegant simplicity. Each path finder uses a single RGB channel value (MAX - pixel[rgbIndex]) to make consistent, predictable decisions. Complex "improvements" that break this simplicity destroy the aesthetic entirely.
